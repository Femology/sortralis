# Sortralis v0.1.0

Sortralis is a local-first Rust CLI for evidence-based Soroban contract upgrade analysis.

## Highlights

- Discover Cargo workspaces and likely Soroban contract packages.
- Detect supported Protocol 28 migration risks with stable rule IDs and source evidence.
- Run configured verification, repository tests, and Stellar contract builds.
- Compare storage observations, committed Git revisions, and normalized contract interfaces.
- Inspect local Wasm artifacts through a verified Stellar CLI adapter.
- Render terminal, JSON, SARIF 2.1.0, and self-contained HTML reports.
- Exercise deterministic fixtures and pinned real-world Soroban repositories in CI.

## Release platforms

- Linux x86_64
- macOS arm64
- macOS x86_64
- Windows x86_64

Every archive has a matching SHA-256 checksum sidecar.

## Safety boundary

Passing Sortralis is **not** a security audit and does not prove that a contract upgrade is safe to deploy. Source-derived interface analysis is explicitly an approximation when exact compiled Wasm specification data is unavailable.
